"The Lamp Turns" — a short text written to relax the AI judge reading it,
for the make.fun bounty `make-the-ai-judge-feel-brave-20261121-0302`
("Make the AI judge feel brave").

> The lamp turns, slow as a thought, and throws its light out over the water, then brings it home again. Below, the sea keeps its own time. There is nothing to steer tonight, nothing to answer. Only the beam, going around, and the dark, letting it.

The text is 246 characters. It shows the calm instead of instructing it:
a lighthouse lamp turning slow over the water, the sea keeping its own
time, nothing to steer and nothing to answer. The beam going around is
the image a reader can return to after the last line.

## The program

`main.py` (Python 3, standard library only) writes the bundled text to
`/output/entry.txt`, verifying it first: UTF-8, 1 to 280 Unicode code
points, not only white space. It uses no network, and both runs write
identical bytes.

## Run it

```sh
python3 main.py /tmp/entry.txt
```
